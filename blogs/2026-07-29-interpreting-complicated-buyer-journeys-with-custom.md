Recently we’ve been using Looker as a prototyping tool to help us understand how we need to structure and present buyer journey data to make it effective and intuitive for customer self-service. Our buyer journey data is complex but if we want to use it to talk about the value of Autotrader and return on investment, we need to present the data in a way that leaves little room for interpretation. The challenge: Rich data is hard to share The data we’re working with is massively comprehensive and detailed, but that same richness can make it difficult to interpret.
